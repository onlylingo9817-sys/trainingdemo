# 培训全链路闭环 Demo · 功能清单

> 飞书版本：https://www.feishu.cn/docx/OkYcdmcVdo8GRXx4eKicobQ2nkf
>
> 数据均为模拟值。本清单按现有代码核对整理，用于说明 Demo 已具备的能力范围，不代表真实业务效果。

## 1. 产品范围

四个身份，页面与数据范围随身份切换。

| 身份 | 数据范围 | 可见范围 |
|---|---|---|
| 总部培训部 · 刘翔 | 全国 | 全部页面 |
| 区域老师 · 周丽（华北）/ 陈磊（华东） | 仅本区域 | 除标签管理、配置中心外 |
| 老板 | 全国（只看聚合） | 培训总览、效果追踪、学员明细；不出现姓名与 MID |
| 零售通学员（钱多多 / 黄磊等） | 本人 | 学习中心、任务、考试、演练、学习包、错题本 |

链路：发现问题 → 课题池 → 内容生产 → 挂知识点 → 上架零售通 → 组织培训 → 学员学习 / 测评 / 演练 → 效果回收 → 调优与结项。

## 4. 说明

- 编号按端前缀：`P-` 为 PC 后台，`A-` 为零售通移动端。
- 第 2.8 节评审功能横跨 PC 与移动端：发起、管理、代录在 PC，投票在移动端。
- 数据全部为模拟值，界面保留「示意数据」标识。
- 部分能力仅有交互与状态，未接真实后端：推送、订阅、外部数据同步、评分规则。

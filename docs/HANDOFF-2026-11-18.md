- 页面截图/探针：`python3 tests/shot.py shot src/index.html out.png --js "..." --width 1440 --height 900`

## 4. 本轮关键决策（别推翻重来）

1. 知识点只做「清单 + 完备度」；讲解、题、演练统一在内容中心维护，避免两处造资产。
2. 知识关系是**业务维护**，不是系统推断；演示数据里的关系来自 `h_seed.js` 的 `kpRelSeed()`，是种子数据。
3. 老板只看群体聚合，不出现姓名/MID；区域老师数据按区域隔离；调优创建/回滚仅总部。
4. 学习先后顺序只由「先学（前置）」决定；「相关」不参与路径。
5. 单文件构建必须内联 CSS/JS 并通过 `verify:single`（本轮修过 CSS 未内联的 bug）。

## 9. 容易踩的坑

- `render()` 现在会把 dock 从 HTML 里抽走，页面里不要再手写第二个 `.dock`。
- 改 `KP_TABS` 或效果页 tab 数组时，旧值兼容必须一起处理，否则旧链接会落到空白。
- 单文件构建只处理 `src/index.html` 内的外链；新增外部图片/字体会被漏掉，需要同步改 `tools/build-single-file.js`。
- 渲染 Word 时，本机 LibreOffice 需要显式字体配置才能正确显示中文（见本轮临时方案：`FONTCONFIG_PATH` 指向包含系统字体目录的配置）。

# 培训知识点库 v1（标准库草案）

> 版本：v1.0 · 2026-11-19 · 依据汽车学堂知识库（`car-cli knowledge +retrieval`）整理。
> 这是一份**业务标准库**，不是学员数据；学员薄弱在工作台 / 效果追踪。
> 生成方式：`node tools/export-taxonomy.js`（单一数据源 `src/scripts/x_taxonomy.js`）。

## 0. 三条口径

1. **标签是维度值，不是文件夹。** 一个知识点可以同时挂车型、场景、客户、竞品；归属维度和能力项必须单值。
2. **知识点是能被讲、能被练、能被考、能被实战验证的最小单元。** 不是课程章节。
3. **完备率 = 某车型应覆盖的 P0 知识点中，已具备“主讲解 + 3 题 + 1 练习”的比例。** 不是“标签下有多少条”。

## 1. 维度字典（7 个）

| 维度 | 角色 | 基数 | 取值 |
|---|---|---|---|
| 车型 | 归属 | 多值 | 通用车型；<br>SU7：SU7 标准版、SU7 Pro、SU7 Max、SU7 Ultra<br>YU7：YU7 标准版、YU7 长续航版、YU7 Pro、YU7 Max、YU7 GT<br>澎程 N70：澎程 N70 Pro、澎程 N70 Max<br>澎程 N90：澎程 N90 Max、澎程 N90 Max 探索版 |
| 知识域 | 归属 | **单值** | 品牌文化、本品知识、竞品对比、销售技能、政策权益、交付服务、客户经营、行业洞察 |
| 能力项 | 能力 | **单值** | 探需、产品讲解、试乘试驾、顾虑解除、促单成交、客户经营、带人辅导 |
| 销售阶段 | 上下文 | 多值 | 全阶段、线索与邀约、排程与 PDC、到店接待、试乘试驾、试驾回访、跟进促单、下订与改配、交付及交付后 |
| 客户场景 | 上下文 | 多值 | 通勤、家庭出行、长途自驾、露营户外、商务接待、接送孩子、宠物出行、移动办公 |
| 客户类型 | 上下文 | 多值 | 首购、增换购、家庭用户、企业客户、米粉生态、年轻个人 |
| 竞品 | 上下文 | 多值 | 特斯拉 Model 3、特斯拉 Model Y、理想 L6、理想 L7、理想 L8、理想 L9、问界 M7、问界 M8、问界 M9、极氪 001、极氪 007、极氪 7X、小鹏 G7、小鹏 P7+、蔚来 ES6、乐道 L60、奔驰 GLC |

**约束：**
- 车型是「车系 → 版本」两层树，外加通用车型。知识点可以挂**版本**（如 SU7 Pro）、**车系**（如 SU7，自动覆盖全部版本）或**通用车型**。
- 能力项只允许这 7 项，岗位画像只能引用这 7 项，不允许另起名字。
- 知识域单值；否则“本品 / 竞品 / 销售”会重复计数。
- 车型多值 + 车系继承；SU7 Ultra 是 SU7 车系下的版本值。
- 竞品只做上下文，不做完备率分母（竞品周更，会漂）。
- 行业洞察 v1 预留，不铺知识点，不进分母。
